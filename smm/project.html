Откуда берём данные
Сейчас работает только ручная вставка. Остальное — заглушки с техзаданием.
Файл CSV или Excel Колонки файла станут фактами строки автоматически. заглушка нужен загрузчик таблиц
Google Sheets Таблица остаётся живой: поправили строку — перегенерили страницу. заглушка нужен доступ к листу

Вставить руками По строке на ключ, факты через точку с запятой. работает быстрый старт

    Факты бэкенд в работе
    Все ли данные из строки дошли до текста и нет ли выдуманных цифр. Доля подтверждённого ниже 60% → брак.
    Сейчас проверка бинарная: любой непопавший факт валит страницу целиком. Нужно две метрики вместо одного флажка:
    • Покрытие данных — сколько полей строки реально упомянуто в тексте
    • Поддержанность цифр — каждое чи��ло в тексте есть в исходных данных
    • Список потерянных фактов и список подозрительных чисел в карточке страницы

    Зачем волны, а не всё сразу
